# 数独教练 v5 Beta

这是一次架构重构，不再在单个 HTML 内持续打补丁。

## 模块
- `js/core.js`：棋盘、候选、撤销、状态
- `js/solver.js`：提示/解题逻辑
- `js/scanner.js`：图片、棋盘定位、透视、OCR
- `js/trainer.js`：Wing 专项训练内容
- `js/app.js`：UI 与模块连接
- `css/app.css`：iPhone 优先界面

## 本 Beta 的重点
1. 扫描流程改为：选图 → 自动找棋盘 → 人工确认 → 拉正预览 → OCR → 校对 → 导入。
2. OCR 不再和棋盘定位混在一起。
3. W-Wing / XY-Wing 专练改为分步骤教学。
4. Solver 与候选状态独立，候选删除可持久保存。

## v5.1 主功能强化：遇到困难时的分步学习
- “做题”页直接增加【开始引导】，不需要切换到提示页。
- 提示分为四层：方向 → 结构 → 推理 → 完整逻辑。
- 前两层故意不直接给删除/填入答案，保留学习空间。
- 第四层才显示完整结论，并允许【执行这一步】。
- 执行后显示“本步学习卡”：刚才发生了什么、识别要点、以后如何迁移。
- W-Wing / XY-Wing / X-Wing / 单数 / 锁定候选 / 数组等都有专门的学习提示文案。
